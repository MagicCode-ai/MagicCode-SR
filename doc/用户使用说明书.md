# MagicCode Super-Resolution（MagicSR）用户使用说明书

版本：v1.1.0  
适用：Native SDK / Unity 插件 / Unreal Engine 插件  
平台：Android（Vulkan / OpenGLES）、iOS / macOS（Metal）、Windows（OpenGL）

English: [`User_Guide.md`](User_Guide.md)

---

## 1. 产品简介

MagicSR 是 MagicCode 超分辨率 SDK，可将输入的 GPU 纹理放大并增强细节，适用于游戏画面、相机预览、UI 纹理等场景。

**推荐接入方式**（两步即可）：

1. `Enable`：输入一张 GPU 纹理，返回超分后的输出纹理  
2. `Disable`：结束使用时释放内部会话与输出纹理  

无需手动创建会话、选择后端或配置输入类型；这些由 `Enable` 内部自动完成。

| 层级 | 公开 API |
|------|----------|
| Native | `MC_Enable` / `MC_Disable` |
| Unity | `MagicSR.Enable` / `MagicSR.Disable` |
| Unreal | `UMagicSRBlueprintLibrary::Enable` / `Disable` |

插件公开 API 是对 Native `MC_Enable` / `MC_Disable` 的薄封装，业务代码应调用插件 API，而不是直接调用 `MC_*`。

## 2. 快速开始

### 2.1 Unity

```csharp
using MagicSR.UnityPlugin;
using UnityEngine;

public class MyUpscale : MonoBehaviour
{
    public RenderTexture inputRT;   // RGBA8 输入
    public float scale = 2.0f;

    void Start()
    {
        // 建议：把模型目录设为可读写路径（含 magic_veryfast_*_params.bin）
        MagicSR.SetModelDir(Application.persistentDataPath + "/MagicSRModels");
    }

    void OnRenderImage(RenderTexture src, RenderTexture dst)
    {
        // 每帧：超分一帧（scale/尺寸不变时会自动复用会话）
        System.IntPtr outNative = MagicSR.Enable(src, scale);
        if (outNative == System.IntPtr.Zero)
        {
            Graphics.Blit(src, dst);
            return;
        }

        // 用输出 native 纹理创建/更新外部 Texture 再 blit（参见 MagicSRCameraUpscaler）
        // ...
        Graphics.Blit(src, dst); // 示例占位
    }

    void OnDestroy()
    {
        MagicSR.Disable(); // 唯一合法的释放方式
    }
}
```

也可直接传 native 指针：

```csharp
IntPtr outPtr = MagicSR.Enable(inputRT.GetNativeTexturePtr(), 2.0f);
MagicSR.Disable();
```

可选：`Enable_3params` / `Enable_4params` 指定模式 / 后端。

内置相机示例：挂载 `MagicSRCameraUpscaler`（Built-in 管线 `OnRenderImage` → `Enable`）。

### 2.2 Unreal Engine（C++）

```cpp
#include "MagicSRBlueprintLibrary.h"

// 每帧（或输入就绪时）
int64 OutNativeTex = UMagicSRBlueprintLibrary::Enable(InputNativeTexture, /*Scale=*/2.0f);
if (OutNativeTex == 0)
{
    // 失败处理
}

// 可选：Enable_3params / Enable_4params / SetInputSizeHint（Android Vulkan）

// 结束时
UMagicSRBlueprintLibrary::Disable();
```

Blueprint：`MagicSR | Easy` → **Enable** / **Enable_3params** / **Enable_4params** / **Disable**。

`InputNativeTexture` 为 native GPU 句柄（`int64`）：

| 后端 | 传入内容 |
|------|----------|
| Metal | `MTLTexture*` 指针转 `int64` |
| OpenGLES | `GLuint` 纹理 ID 转 `int64` |
| Vulkan | `VulkanTexture*` / 指向 `VkImage` 的指针转 `int64` |

### 2.3 Native C

```c
#include "mc_enable.h"

void* out = MC_Enable(input_texture, 2.0f);  // RGBA GPU 纹理
if (out == NULL) { /* 失败 */ }

/* 使用 out（借出指针，不要 free / CFRelease / glDelete） */

MC_Disable(NULL);  // 或 MC_Disable(out)；参数可忽略

/* 可选：指定模式 / 后端 */
/* void* out = MC_Enable_3params(input_texture, 2.0f, HIGH_SPEED_MODE); */
/* void* out = MC_Enable_4params(input_texture, 2.0f, HIGH_SPEED_MODE, MAGIC_BACKEND_DEFAULT); */```

## 3. Enable 行为说明

| 项目 | 说明 |
|------|------|
| 功能 | 懒初始化会话 + 处理一帧 + 返回输出 GPU 纹理 |
| `scale` | `float`，范围 `[1.0, 8.0]`；`<= 0` 时默认为 `2.0` |
| 会话复用 | 相同 `scale`、输入宽高、mode、backend 时复用内部会话与输出纹理 |
| 返回值 | 输出纹理指针；失败为 `NULL` / `IntPtr.Zero` / `0` |
| 所有权 | 输出由库持有，**只能**通过 `Disable` 释放 |

### 3.1 输入纹理格式（重要）

`Enable` 统一要求 **RGBA 系** GPU 纹理：

| 平台 / 后端 | 输入格式 | `Enable` 后端 |
|-------------|----------|----------------|
| iOS / macOS Metal | `RGBA8Unorm`（`MTLTexture*`） | Metal |
| Windows OpenGL | `RGBA8`（`GLuint` 转 `void*`） | OpenGL |
| Android OpenGLES | `RGBA8`（`GLuint` 转 `void*`） | OpenGLES |
| Android Vulkan | `RGB8Unorm` / `RGBA8` | Vulkan |

Unity 示例：使用 `GraphicsFormat.R8G8B8A8_UNorm` 的 `RenderTexture`。  
不要再向 `Enable` 传入 R8 单通道纹理。

### 3.2 尺寸与性能提示

- 输入宽高一般需在 SDK 支持范围内（常见约 64～4032）。  
- Android Vulkan 在无法查询 `VkImage` 尺寸时，内部可能按固定尺寸回退（当前实现约 720×1280）；请尽量保证输入纹理尺寸与会话一致。  
- `scale` / 尺寸频繁变化会触发重建，影响性能。

## 4. 模型文件

`Enable` 会按以下顺序查找模型（摘要）：

1. 环境变量 `MAGIC_SR_MODEL`（完整文件路径）  
2. 环境变量 `MAGIC_SR_MODEL_DIR`（目录 + 默认文件名）  
3. 相对路径 / 平台默认目录（如 Android `Documents/MagicSRModels`）  
4. iOS：App Bundle 内嵌模型  

常用模型文件名：

| 场景 | 文件 |
|------|------|
| Metal / Vulkan（GPU） | `magic_veryfast_gpu_params.bin` |
| Windows OpenGL | `magic_veryfast_gpu_params.bin` / `magic_gl_highspeed_gpu_params.bin` |
| OpenGLES | `magic_veryfast_gles_params.bin` |

### Unity

- 将模型放到 `StreamingAssets/MagicSRModels/`  
- 运行时建议复制到 `persistentDataPath/MagicSRModels/`，并调用：

```csharp
MagicSR.SetModelDir(Application.persistentDataPath + "/MagicSRModels");
```

### Unreal

- 将模型放到 `Content/MagicSRModels/`  
- 打包后确保设备侧可访问（例如拷贝到应用沙箱 `Documents/MagicSRModels`，或设置 `MAGIC_SR_MODEL` / `MAGIC_SR_MODEL_DIR`）

## 5. 集成步骤

### 5.1 Unity

1. 引入 C# 脚本：`plugin/unity/CSharp/`（至少 `MagicSR.cs`、`MagicSRNative.cs`）  
2. 构建并放入 Native 插件：  
   - Android：`libmagic_sr_unity.so` → `Assets/Plugins/Android/`  
   - iOS：`libmagic_sr_unity_ios.a` → `Assets/Plugins/iOS/`  
3. 放入模型到 `StreamingAssets/MagicSRModels/`  
4. 调用 `MagicSR.SetModelDir`（推荐）→ `Enable` → `Disable`

构建脚本参考：

- `plugin/unity/Native/build_android.sh`  
- `plugin/unity/Native/build_ios.sh`  
- 样例工程：`plugin/unity/Samples/AndroidSmokeTest/`

### 5.2 Unreal Engine

1. 复制插件到工程：`<YourProject>/Plugins/MagicSR`  
2. 确保已链接发布库：  
   - `release/v1.1.0/lib/android/libmagic_sr.a`  
   - `release/v1.1.0/lib/ios/libmagic_sr.a`  
3. 在 `.uproject` 中启用 MagicSR，重新生成工程 / 打开编辑器  
4. Blueprint 或 C++ 调用 `Enable` / `Disable`  
5. 放入模型：`Content/MagicSRModels/`

样例工程：`plugin/ue/Samples/AndroidSmokeTest/`

### 5.3 Native

1. 包含头文件：`interface/mc_enable.h`（及 `mc_interface.h`）  
2. 链接 `libmagic_sr.a`（按平台选择 android / ios）  
3. iOS 还需链接 Metal / MetalKit 等相关系统框架  
4. 调用 `MC_Enable` / `MC_Disable`

## 6. 内存与生命周期（必读）

1. **`Enable` 返回的输出纹理是借出（borrowed）指针**  
   - 不要 `free` / `delete` / `CFRelease` / `glDeleteTextures` / `DestroyImmediate`  
   - iOS Metal：错误 `CFRelease` 会在释放点直接 `abort`  
2. **唯一合法释放方式是 `Disable()`**  
3. `Disable` 之后，此前返回的输出指针全部失效，不可再使用  
4. 可反复 `Enable`；在 `scale` 与尺寸不变时会复用内部资源  
5. `Disable` 后再次 `Enable` 会重新创建会话

## 7. 进阶 API（可选）

若需要显式控制输入/输出纹理、后端或 CPU Buffer 路径，可使用会话式 API：

| 平台 | API |
|------|-----|
| Native | `MC_Init` / `MC_Process` / `MC_Uninit` |
| Unity | `MagicSRSession.CreateEx` + `ProcessTexture` |
| Unreal | `CreateSessionEx` + `ProcessUTexture` / `ProcessNativeTexture` |

`InputType` / `Backend` 取值见 `mc_interface.h`。  
**普通游戏 / 相机接入优先使用 `Enable` / `Disable`，无需会话 API。**

## 8. 常见问题

**Q: Enable 返回空指针？**  
A: 检查模型是否可读、`SetModelDir` / 模型路径是否正确、输入纹理格式是否为 RGBA、尺寸是否合法、GPU 后端是否可用。

**Q: 为什么 iOS 不能再用 R8？**  
A: 当前 `MC_Enable` 默认输入为 RGBA。R8 仅适用于旧的会话式 Metal/GLES 高级路径，不适用于 `Enable`。

**Q: 输出花屏 / 全黑？**  
A: 确认输入为 RGBA8、未对输出做非法释放、Vulkan 输入尺寸与会话一致；查看 log 中的 MagicSR / Unity / UE 错误码。

**Q: 相机 / URP / HDRP 怎么接？**  
A: 将画面 resolve / blit 到一张 RGBA `RenderTexture`（或等价 native 纹理），再调用同一个 `Enable(texture, scale)`。无专用 Camera Enable API。

**Q: 可以多实例同时 Enable 吗？**  
A: `Enable` 路径是进程内单例。多路并发请改用会话式 API，或串行共享同一 `Enable` 会话。
