# Magic Magnifier Demo

Camera magnifier demo based on MagicSR (`MC_Enable*`):

- Android (OpenGLES)
- iOS / iPadOS (Metal)
- Continuous zoom `[1.0, 8.0]` via center-crop + SR
- Modes: `highspeed` / `speed`

## Layout (repo-relative)

```text
MagicCode-SR/
  interface/                 # Public headers (mc_enable.h, mc_interface.h)
  lib/
    android/libmagic_sr.a
    ios/libmagic_sr.a
  model/                     # SR model bins
  demo/
    android/                 # Android Studio project
      packages/              # Prebuilt Android APK
    ios/                     # Xcode project
    build_demo.sh / .bat
    README.md
```

Demo builds **must** link:

| Platform | Library | Headers |
|----------|---------|---------|
| Android | `../../lib/android/libmagic_sr.a` (from `demo/`) | `../../interface/` |
| iOS | `../../lib/ios/libmagic_sr.a` | `../../interface/` |

## Required files

- `lib/android/libmagic_sr.a`
- `lib/ios/libmagic_sr.a`
- `interface/mc_enable.h`
- `interface/mc_interface.h`
- `model/magic_gles_{highspeed,speed}_gpu_params.bin`
- `model/magic_metal_{highspeed,speed}_gpu_params.bin`

## Build

From `demo/`:

```bash
./build_demo.sh          # macOS / Linux → Android APK
# or
build_demo.bat           # Windows → Android APK
```

Manual Android:

```bash
cd android
./gradlew :app:assembleDebug
```

iOS (macOS + Xcode — run on device from Xcode; no prebuilt IPA):

```bash
open ios/MagicCameraSR.xcodeproj
# or
cd ios
xcodebuild -project MagicCameraSR.xcodeproj \
  -scheme MagicMagnifierSR \
  -configuration Debug \
  -sdk iphoneos build
```

## Prebuilt Android package

After a successful Android build, the script copies:

- `demo/android/packages/MagicMagnifierSR-android-arm64.apk`

Install:

```bash
adb install -r android/packages/MagicMagnifierSR-android-arm64.apk
```

## Runtime

1. Grant camera permission
2. Select `highspeed` or `speed`
3. Drag the scale slider — the view crops the center by `1/scale` then runs SR

## What not to commit under `demo/`

Build caches and intermediates (safe to delete; regenerated by build):

- `android/.gradle/`
- `android/app/build/`
- `android/app/.cxx/`
- `ios/**/xcuserdata/`
- `ios/Build/` (if present)
- `.DS_Store`

Keep source: `android/app/src/`, Gradle wrappers, `ios/MagicCameraSR/`, `.xcodeproj`, scripts, `android/packages/*.apk` (optional).
